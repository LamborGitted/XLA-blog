# XLA blog pages 

一个具有特色的博客页面

---

### 目前具有的功能
+ 文章列表
+ 文章阅读（上一篇、下一篇）
+ 亮暗主题切换
+ 主题颜色基于颜色滑动选取
+ 外链导航岛
+ 搜索、过滤文章

### 安全特性
+ **XSS 防护**：集成 DOMPurify 自动过滤恶意脚本，保护用户安全
+ **内容净化**：仅允许安全的 HTML 标签和属性
+ **协议过滤**：阻止 javascript: 等危险协议
